# Prompt template: characterization tests before a refactoring (v1.0)

Use with: a coding agent (Kilo Code: *Code*).

## Goal
Write characterization tests for `{{function}}` before I refactor it.

## Context
- File: `{{file}}`. It is called from {{callers}} with this preprocessing: {{preprocessing}}.
- Data available: {{data_files}}.

## Constraints
- Do not modify the source. The golden file is generated by the CURRENT code.
- Keep a copy of the current implementation inside the test file as an **oracle**.

## Examples
Random signals including ties and plateaus, several values of each parameter (including 0), inputs of length 0 to 3.

## Format
`tests/test_characterization.py`, a small script that writes `tests/golden/<name>.json`.

## Verification
All tests pass on the current, unchanged implementation. Show the output.
